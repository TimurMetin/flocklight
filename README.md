# FLOCKLIGHT — Guide the Unseen

An interactive game exploring **Agency × Emergence**.

## Play the Game

https://timurmetin.github.io/flocklight/

## Premises

**01 — Agency:** Players influence the system by placing up to three light beacons. Placement rules and limited resources make each decision meaningful.

**07 — Emergence:** Fireflies respond to nearby neighbours through alignment, cohesion, and separation, producing collective movement that is not individually scripted.

## How to Play

Guide at least 16 of 24 fireflies to the Moon Gate. Place three light beacons in sequence to create a safe route. Avoid dangerous trees and observe how the swarm reacts.

Controls: Mouse, touch, keyboard, or on-screen buttons.

## Technologies

HTML5, CSS3, JavaScript and Canvas. No server or external framework is required.

## Readings

- Wardrip-Fruin et al. (2009). *Agency Reconsidered*.
- Reynolds (1987). *Flocks, Herds, and Schools: A Distributed Behavioral Model*.

## Credits and AI Use

Original game concept and implementation developed for NMED 3203 Interactive Media Applications.

ChatGPT was used for brainstorming, code generation, debugging, and drafting support. An earlier implementation allowed fireflies to reach the exit regardless of meaningful beacon placement. That approach was rejected and replaced with sequential checkpoints, limited attraction ranges, and environmental hazards.
